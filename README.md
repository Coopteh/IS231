## УП, ПП 06.01 "Сопровождение информационных систем"   

Срок сдачи отчета по учебной и производственной практикам: 29.12.2025  

### Индивидуальное задание на учебную практику (для хилых духом)  

Индивидуальное задание заключается в изучении методов и средств инженерно-технической поддержки сопровождения информационной системы:  
- Изучение настроек доступа к сетевым устройствам
- Изучение политики безопасности
- Изучение создания резервной копии информационной системы
- Изучение создания резервной копии базы данных
- Изучение восстановления данных
- Изучение восстановлении информационной системы
- Исследование механизмов сбора информации об ошибках и формирования отчетов  
- Рассмотрение вопросов обслуживания информационной системы в соответствии с пользовательской документацией
- Освоение способов обслуживания локальной сети  
- Изучение документирования процессов внедрения и сопровождения информационных систем  
- Исследование сценария внедрения информационной системы для рабочего места  
- Исследование технического задания на внедрение информационной системы  
- Исследование графика разработки и внедрения информационной системы  
- Исследование перечня обучающей документации на информационную систему  
- Исследование технического задания на сопровождение информационной системы
- Рассмотрение способов формирования предложений о расширении информационной системы

### Индивидуальное задание на производственную практику (для хилых духом)  

Индивидуальное задание заключается в использовании методов и средств инженерно-технической поддержки сопровождения информационной системы:  
- Настройке доступа к сетевым устройствам
- Настройке политики безопасности
- Создании резервной копии информационной системы
- Создании резервной копии базы данных
- Восстановлении данных
- Восстановлении информационной системы
- Сборе информации об ошибках. Формирование отчетов об ошибках
- Выполнение обслуживания информационной системы в соответствии с пользовательской документацией
- Обслуживание локальной сети  
- Документирование процессов внедрения и сопровождения информационных систем  
- Разработка сценария внедрения информационной системы для рабочего места  
- Разработка технического задания на внедрение информационной системы  
- Разработка графика разработки и внедрения информационной системы  
- Разработка перечня обучающей документации на информационную систему  
- Разработка технического задания на сопровождение информационной системы
- Формирование предложений о расширении информационной системы

### Пакет документов  
Пакет документов должен включать 2 отчета:  

Отчет по учебной практике + Индивидуальное задание по учебной практике + Дневник прохождения + Характеристика с предприятия + Аттестационный лист  
Отчет по производственной практике + Индивидуальное задание по производственной практике + Дневник прохождения + Характеристика с предприятия + Аттестационный лист  
Печати ставить где указано место печати (М.П. - в Характеристике и Аттестационном листе)
