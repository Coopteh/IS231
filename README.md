## Метрики продуктаа
Задача - аргументировать раздел курсовой "Анализ предметной области" 
```
Анализ предметной области онлайн торговли в сфере ... показывает рост объема продаж (пиццы, мебели, ..) через интернет.
Об этом говорят показатели метрики LTV (пожизненная ценность клиента), CAC (метрика ..), RR (метрика ..)
```
Определите и запишите для курсовой (\storage\Product_metric.docx):  
- средний LTV для вашей сферы;   
- средний CAC для вашей сферы;    
- средний RR для вашей сферы;  
- определите какие компании с высоким RR (удержание клиентов) в России в вашей сфере?  
Это лучшие компании в вашей отрасли, на которые надо равняться и сильные стороны которых следует перенимать.
Желательно, найти в интеренете диаграммы и графики динамики показателей.
Оформите в рамках единого документа главы "Анализ предметной области" для вашей курсовой.
