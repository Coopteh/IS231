### УП, ПП 05.01 "Проектирование и разработка информационных систем"  

Цель:  
Приобретение практического опыта в проектировании и разработке информационных систем,  
развитие профессиональных компетенций и навыков, необходимых для успешного выполнения задач в данной области.  

Срок сдачи отчета по учебной и производственной практикам - сдаем 22.06.2026 (в понедельник)  

Задания:  
- Сбор исходных данных для проектной документации:  
проведите анализ предметной области, соберите и систематизируйте данные,
необходимые для проектирования информационной системы;  
подготовьте отчет о проведенных интервью с пользователями и выявленных требованиях.  
- Формулирование требований к информационной системе:
разработайте функциональные и нефункциональные требования к проектируемой системе;
составьте описание сценариев использования системы (use-case).  
- Разработка проектной документации: создайте техническое задание (ТЗ)
на разработку информационной системы на основе собранных данных;  
оформите проектную документацию в соответствии с установленными стандартами.  
- Проектирование архитектуры информационной системы:  
определите архитектурный подход для проектируемой системы (клиент-серверная, микросервисная и т.д.);
разработайте схемы и диаграммы, описывающие архитектуру системы.  
- Разработка подсистем безопасности: проведите анализ угроз безопасности для проектируемой системы;
разработайте меры защиты данных и проектируйте подсистему аутентификации и авторизации.  
- Программирование модулей информационной системы: реализуйте один из модулей системы
согласно техническому заданию; используйте соответствующий язык программирования и инструменты разработки.  
- Тестирование информационной системы: проведите функциональное тестирование разработанного модуля;
документируйте результаты тестирования и выявленные ошибки.  
- Разработка технической документации на эксплуатацию: создайте инструкции по эксплуатации
и обслуживанию системы для пользователей; подготовьте документацию для администраторов системы.  
- Оценка качества функционирования информационной системы:  
проведите анализ производительности разработанной информационной системы;
составьте отчет о качестве работы системы с рекомендациями по улучшению.  
- Модернизация информационной системы: на основе анализа текущего состояния ИС
предложите план модернизации, включая обновление функционала или технологий.  

### Пакет документов  
Пакет документов должен включать 2 отчета:  

Отчет по учебной практике + Индивидуальное задание по учебной практике + Дневник прохождения + Характеристика с предприятия + Аттестационный лист  
Отчет по производственной практике + Индивидуальное задание по производственной практике + Дневник прохождения + Характеристика с предприятия + Аттестационный лист
