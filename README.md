Проведение PEST-анализа
Цель работы: 
Научиться анализировать внешнюю среду продукта, используя PEST-анализ, и формулировать выводы на основе полученных данных.

Шаги выполнения задания:
1. Выберите свой продукт:
Проектирование и разработка веб-сайта для ИС «...»

2. Проведите PEST-анализ:
Изучите четыре группы факторов:

o Политические (Political): Законы, регулирование, политическая стабильность.

o Экономические (Economic): Уровень дохода, инфляция, экономический рост.

o Социальные (Social): Демография, культурные особенности, привычки пользователей.

o Технологические (Technological): Инновации, доступность технологий, тренды.

3. Соберите данные:
Используйте вторичные источники (отчеты, статьи, статистику) и, если возможно, первичные данные (опросы, интервью).

4. Проанализируйте данные:
Определите, какие факторы представляют возможности для продукта, а какие — угрозы.

5. Оформите результаты:
Подготовьте отчет с результатами анализа.
