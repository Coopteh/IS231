# IS231
Задачи для группы ИС-231
                             ИС "Кинотеатр" - PEST-анализ
Веб-сайт для онлайн-продажи билетов и управления сеансами
📋 Продукт

------------------------------------------------------------------------------------------

Название: Информационная система «Кинотеатр»

Назначение: Онлайн-бронирование и покупка билетов, просмотр расписания, персональные рекомендации

Целевая аудитория: Зрители 16-45 лет, активные пользователи смартфонов

-------------------------------------------------------------------------------------------

🔍 PEST-анализ
🏛️ Политические:
Фактор:
✅ Поддержка цифровизации культуры (МЭР РФ)
✅ 54-ФЗ (онлайн-кассы)
⚠️ 115-ФЗ, 161-ФЗ (платежи, AML)
⚠️ Санкционные ограничения
Влияния:
🟢 Возможность: гранты, льготы для IT-проектов
🟢 Возможность: готовая экосистема фискализации
🔴 Угроза: усложнение интеграции платёжных систем
🔴 Угроза: зависимость от отечественных сервисов

💰 Economic (Экономические)
Фактор:
✅ Рост e-commerce в РФ (+12-15%/год)
✅ Развитие СБП и безналичных платежей
⚠️ Инфляция, снижение реальных доходов
⚠️ Волатильность курса валют
Влияние:
🟢 Возможность: рост спроса на онлайн-покупки
🟢 Возможность: высокая конверсия оплаты
🔴 Угроза: чувствительность к цене билетов
🔴 Угроза: рост затрат на импортное ПО/оборудование

👥 Social (Социальные)
Фактор:
✅ Мобильный трафик >70%
✅ Спрос на персонализацию
✅ Интерес к российскому кино
⚠️ Конкуренция со стримингами
Влияние:
🟢 Возможность: AI-рекомендации, лояльность
🟢 Возможность: mobile-first дизайн, PWA
🟢 Возможность: партнёрство с локальными студиями
🔴 Угроза: снижение частоты посещений кинотеатров

⚙️ Technological (Технологические)
Фактор:
✅ Российские облака (Yandex Cloud, SberCloud)
✅ QR-билеты и e-ticketing
✅ Интеграция с VK ID, Яндекс, Госуслуги
⚠️ Требования 152-ФЗ (персданные)
⚠️ Быстрое устаревание стека
Влияние:
🟢 Возможность: бесконтактный вход, удобство
🟢 Возможность: масштабируемость, отказоустойчивость
🟢 Возможность: быстрая авторизация, охват аудитории
🔴 Угроза: затраты на безопасность и аудит
🔴 Угроза: необходимость постоянного обновления

----------------------------------------------------------------------------------------------

🎯 Выводы
✅ Ключевые возможности:
   • Mobile-first + PWA для роста конверсии
   • Персонализация через историю просмотров
   • Интеграция со СБП, VK, Яндекс.Афиша
   • Участие в госпрограммах цифровизации

⚠️ Основные угрозы:
   • Экономическая нестабильность → гибкое ценообразование
   • Конкуренция со стримингом → акцент на премиум-опыт (IMAX, премьеры)
   • Регуляторные требования → заранее проработать 152-ФЗ и 54-ФЗ

----------------------------------------------------------------------------------------------

🛠️ Рекомендации для разработки
Реализовать адаптивный интерфейс (mobile-first)
Внедрить модуль динамического ценообразования
Подключить ЮKassa + СБП + Tinkoff Pay
Обеспечить шифрование и хранение персданных по 152-ФЗ
Добавить API для будущих интеграций (моб. приложение, партнёры)
