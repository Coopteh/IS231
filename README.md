Запустите XAMPP +Apache +mySQL, вызовите phpMyAdmin  
Создайте базу данных db_customers,  
в ней таблицу customers c полями, соответствующими названиям полей из json.  

Работа с git
```
запустите Git Bash
перейдите в каталог c:/xampp/htdocs
> cd c:/xampp/htdocs

Создайте новую ветку import-from-json
```

Выполните импорт данных 2 способами:
1 способ - Импорт sql-скриптом
```
сделайте копию customers.json и переименуюте в customers.sql 
в phpMyAdmin нажмите вкладку SQL для таблицы customers
нажмите шаблон для INSERT запроса - добавьте этот шаблон в customers.sql заменив
 ":" на "=", скобки "{" и "}" на "(" и ")"
Добейтесь успешного выполнения INSERT-запросов из файла в phpMyAdmin
(в таблице customers должны появиться 6 записей)
```
2 способ - Импорт php-скриптом
```
Откройте VS Code, создайте новый файл import_json.php
Напишите код, который:
- открывает файл customers.json на чтение
- использует функцию json_decode(), чтобы преобразовать "сырые" json-данные в ассоциативный массив
- уставнавливает PDO-соединение в базой данных db_customers
- выполняет sql-запросы INSERT в цикле по всем элементам полученного массива
```
Добейтесь успешного выполнения кода.

Закоммитьте и запуште изменения.
Создайте Pull request.
