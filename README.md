Это критерий покрытия, при котором тестирование должно обеспечить выполнение всех возможных исходов каждого пункта принятия решения отя бы один раз
___________________________________________________________
Метод покрытия операторов.

Требуется составить такой набор тестов, чтобы каждая исполняемая строка кода в программе была выполнена хотя бы один раз
___________________________________________________________
Метод покрытия условий.

Требуется, чтобы каждое элементарное булево условие внутри составного логического выражения приняло значение True и False хотя бы по одному разу
___________________________________________________________
Метод комбинаторного покрытия условий.
