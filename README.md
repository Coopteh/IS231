# PEST-анализ для ИС «Туристическая фирма»

**Продукт:** Проектирование и разработка веб-сайта для ИС «Туристическая фирма»
**Отрасль:** Онлайн-торговля туристическими услугами (E-travel)
**Студент:** Бибик Илья Сергеевич

## Цель работы
Анализ внешней среды продукта для выявления возможностей и угроз при разработке веб-сайта туристической фирмы.

## PEST-анализ

### 1. Политические факторы (Political)
- **Возможность:** 
  - Государственная поддержка внутреннего туризма (субсидии, кэшбэк).
  - Упрощение визового режима со странами-партнерами (Азия, Ближний Восток).
  - Интеграция с государственными цифровыми сервисами.
- **Угроза:** 
  - Геополитическая нестабильность и закрытие направлений.
  - Ужесточение законодательства о персональных данных туристов.
  - Изменения в налогообложении онлайн-продаж услуг.

### 2. Экономические факторы (Economic)
- **Возможность:** 
  - Рост спроса на бюджетный туризм и туры выходного дня.
  - Внедрение сервисов рассрочки (BNPL) для покупки туров.
  - Переориентация спроса на внутренний рынок из-за курса валют.
- **Угроза:** 
  - Высокая инфляция и рост стоимости логистики (авиабилеты, отели).
  - Волатильность курсов валют, усложняющая ценообразование.
  - Снижение располагаемых доходов населения.

### 3. Социальные факторы (Social)
- **Возможность:** 
  - Тренд на индивидуальные и авторские туры (конструкторы туров на сайте).
  - Развитие направления для удаленных работников (Digital Nomads).
  - Повышенный запрос на безопасность и медицинское страхование.
- **Угроза:** 
  - Риски эпидемий, влияющие на желание путешествовать.
  - Необходимость адаптации интерфейса под стареющее население.
  - Эко-тренды, снижающие популярность авиаперелетов.

### 4. Технологические факторы (Technological)
- **Возможность:** 
  - Использование AI для персонализированного подбора туров и чат-ботов.
  - Внедрение VR/AR для виртуальных туров по отелям.
  - Разработка PWA (Progressive Web App) для мобильного доступа.
- **Угроза:** 
  - Кибератаки и риск утечки паспортных данных клиентов.
  - Конкуренция с крупными агрегаторами и экосистемами.
  - Быстрое устаревание технологического стека и API партнеров.

## Итог
Разрабатываемый веб-сайт должен иметь гибкую архитектуру для быстрой смены направлений, модуль безопасности высшего уровня и интеграцию с AI-сервисами. Ключевой фокус — на внутреннем туризме и персонализации предложения для компенсации экономических и политических рисков.
