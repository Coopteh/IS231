## Проверить на соответствие стандартам PSR

Работаем с тем же проектом (проект для блога), что и на предыдущем занятии (ветка task25602).
Задача установить 3 статических анализатора, проверить соответствие стандартам PSR,  
исправить ошибки (автоматически, с помощью стат.анализатора) и отправить изменения в репозиторий.  

Работа с git
```
запустите Git Bash
перейдите в каталог c:/xampp/htdocs
> cd c:/xampp/htdocs

Сделайте Sync fork в своем репозитории IS231 для форкнутой репы из Coopteh/IS231
и настроим обновление веток в терминале
> git remote add coopteh https://github.com/Coopteh/IS231.git
получим обновления веток с оригинального репозитория (на coopteh)
> git fetch coopteh

выполните в bash терминале
> git pull
переключитесь на ветку task2502
> git checkout task2502
```
Установите и запустите статистические анализаторы
```
установка PHP_CodeSniffer (анализирует ваш код и сообщает о несоответствиях)
> composer require --dev squizlabs/php_codesniffer
запуск: - чтобы проверить код в папке src на соответствие стандарту PSR-12:
> vendor/bin/phpcs --standard=PSR12 src/

установка PHPStan (проверяет код на наличие ошибок и предупреждений, даже если код соответствует стандартам).
Он помогает находить такие проблемы, как:
• Использование несуществующих методов.
• Нарушение типов данных.
• Потенциально некорректная логика.
> composer require --dev phpstan/phpstan
Настройка - cоздайте файл phpstan.neon для конфигурации:
> nano phpstan.neon
запишите в файл
parameters:
    level: 5
    paths:
        - src
Запуск - чтобы проверить код, выполните:
> vendor/bin/phpstan analyse

PHP-CS-Fixer — инструмент, который не только находит проблемы в коде, но и автоматически исправляет их.
Он особенно удобен для применения стиля PSR.
Установка:
> composer require --dev friendsofphp/php-cs-fixer
Запуск - для автоматического исправления стиля в папке src выполните:
> vendor/bin/php-cs-fixer fix
- везде (0) в конце Enter

После автоматического исправления php-cs-fixer - запустите повторно phpcs
> vendor/bin/phpcs --standard=PSR12 src/

Ошибок быть не должно!
```

Закоммитьте и запуште изменения
```
> git status
> git add .
> git status
> git commit -m "Статистические анализаторы"
> git push
```
