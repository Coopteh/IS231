# IS231
Задачи для группы ИС-231
-Тестирование по методу белого ящика - способ проверки ПО, фокусирующийся на внутренней системе и коде программы.
-Покртие операторов - метод тестирование по белому ящику, при котором все исполняемые операторы исходного кода выполняются хотя бы один раз
-Покрытие условий - один из методов тестирование по белому ящику. Каждое логическое выражение проверяется в условных операторах. При таков подходе каждое булево подвыражение оценивается как истина и ложь назависомо, что позволяет выявить дефекты внутри алгоритмы
