Тестирование по белому ячику (white-box testing) — метод тестирования программного обеспечения, при котором проверяется внутренняя структура программы, её логика исполнения, пути прохождения команд и контроль потоков данных внутри приложения. 

Покрытие операторов (statement coverage) — метрика качества тестов, определяющая процент строк кода (или операторов), выполненных хотя бы одним тестовым случаем. 
Покрытие условий (decision coverage) — уровень теста, показывающий долю всех возможных результатов ветвлений (условий), проверенных в ходе тестирования.

Метод покрытия операторов
Метод основан на запуске тестовых случаев таким образом, чтобы каждый оператор исполнялся хотя бы однажды. Это простой способ проверки базового функционала программы, однако он не гарантирует выявления ошибок, возникающих вследствие сложных взаимодействий элементов программы.

Метод покрытия условий
При таком подходе тесты составляются так, чтобы проверить каждое возможное направление ветви условных выражений («если-то»).

Метод комбинаторного покрытия условий
Комбинаторное покрытие условий требует тестирования всех возможных сочетаний значений входных параметров условий. Этот подход особенно полезен для ситуаций, когда сочетание разных значений может привести к уникальным путям исполнения программы.
