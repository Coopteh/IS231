Продукт: Веб-сайт для онлайн-торговли компьютерной техникой   
Отрасль: Электронная коммерция

1. Политические факторы
Возможность: Поддержка цифровизации МСП, упрощение электронных платежей
Угроза: Ужесточение требований к защите персональных данных, импортные пошлины

2. Экономические факторы
Возможность: Рост e-commerce, развитие онлайн-кредитования
Угроза: Инфляция, волатильность валют, снижение покупательной способности

3. Социальные факторы
Возможность: Рост цифровой грамотности, тренд на удалённую работу
Угроза: Высокие ожидания к сервису, недоверие к онлайн-покупкам дорогой техники

4. Технологические факторы
Возможность: AI-персонализация, облачные архитектуры, мобильная оптимизация
Угроза: Киберугрозы, быстрое устаревание стека, конкуренция с маркетплейсами
